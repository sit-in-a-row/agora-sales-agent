# RTC / media

## Capabilities
- real-time video
- real-time voice
- interactive streaming
- signaling
- chat
- screen-sharing/collaboration use cases
- recording use cases

## Pain points visible in customer cases
- long connection time
- freeze / dropped call
- scalability
- global quality variance
- external-app friction
- customization
- embedded UX
- compliance recording

## Positioning
RTC = “회의 앱”이 아니라, prospect의 app/service 안에 실시간 voice/video/data interaction을 embed하는 infrastructure.
